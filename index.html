PV Tools.

Internal field and review tools — no build step, no dependencies, no network calls.

  • PW3 String Analyzer →
    Tesla Powerwall 3 MPPT string diagnostic. Reads the six DC voltage/current pairs and flags overcurrent, overvoltage, missing or faulty jumpers, dead strings, and imbalance.
  • Lynx →
    PV CT data reviewer. Loads exported graph data for site review, with microinverter troubleshooting.
  • Magpie →
    Note builder.
Each tool is a single self-contained page and works offline from a saved local copy — useful on job sites with no signal. On mobile, use Add to Home Screen.
These pages carry noindex so they stay out of search results, but the URL is unlisted, not secret. Do not enter customer names, addresses, or site data.
