Clear-sky irradiance model. Trees are ellipsoid crowns (trunk ignored). Diffuse light is not reduced by shade. Single array plane, flat terrain. Great for ranking which tree matters, not a bankable energy number. Unlike the other tools in this hub, this one is not offline — the satellite imagery (Esri) and address search (OpenStreetMap Nominatim) load over the network, which also means the pin location / searched address is sent to those providers. Don't search on a customer's exact street address if that's a concern; drop the pin manually instead.
