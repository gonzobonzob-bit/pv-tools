← PV Tools PW3 String Analyzer v5.2

Tesla Powerwall 3 — MPPT configuration diagnostic. Enter the six Solar DC Input readings from Tesla One and get verdicts on overcurrent, overvoltage, jumpers, dead strings and imbalance. AC service voltage and frequency are checked against ANSI C84.1 and IEEE 1547 — the utility-service-voltage standards that determine when the inverter has to stop exporting. Switch to Full site to review a gateway and up to four Powerwalls together, including cross-unit checks that no single screen can show.

Full site review
Paste each device from Tesla One → System → Devices, one at a time. Open a device, copy its vitals, paste below. Readings need not be simultaneous — cross-unit tolerances allow for the gap.
Up to 4 Powerwall 3 base units per gateway. Expansion units have no PV inputs and are not entered here.
Tesla ships two PW3 variants with different PV input current ratings. Check the label in the enclosure. Getting this wrong changes every current verdict below.
Module data optional — enables string counting
Enter Voc to switch string counting on; leave the card empty and the tool behaves exactly as before. The rest falls back to the typical mono values shown as placeholders. Counts come out as a range — cell temperature is not measured and it moves the answer by whole modules.
Fastest input
